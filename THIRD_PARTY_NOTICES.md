# Third-party notices

tuppet is built from its own code and the components below. The table lists which release builds contain each one; the
license texts follow. macOS builds link the system C library dynamically and bundle no C runtime.

| Component | Used for | Builds | License |
| --- | --- | --- | --- |
| [Zig](https://ziglang.org/) standard library and compiler runtime | Runtime support compiled into every binary | All | MIT |
| [Ghostty](https://github.com/ghostty-org/ghostty) | Terminal emulation; `src/input` adapts its key and mouse encoders | All | MIT |
| [uucode](https://github.com/jacobsandlund/uucode) | Unicode properties | All | MIT, with Unicode data under the Unicode License v3 |
| [simdutf](https://github.com/simdutf/simdutf) | Fast UTF-8 and base64 decoding | All | MIT (dual-licensed with Apache-2.0), with code derived from PyTorch under BSD-3-Clause |
| [Highway](https://github.com/google/highway) | SIMD dispatch | All | BSD-3-Clause (dual-licensed with Apache-2.0) |
| VGA 8x16 font (`u_vga16`) | Text in PNG snapshots | All | X11-style |
| [musl libc](https://musl.libc.org/) | C library | Linux | MIT |
| [mingw-w64](https://www.mingw-w64.org/) runtime | C runtime | Windows | ZPL 2.1 |

Ghostty, simdutf, and Highway come from Ghostty revision `3924a3255686b2b646d2ee8730ad5528f4542a26`.
