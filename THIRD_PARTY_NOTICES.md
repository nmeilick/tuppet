# Third-party notices

tuppet is built from its own code and the components below. The table lists which release builds contain each one, by
platform and by font variant (lean, medium, full); the license texts follow. macOS builds link the system C library dynamically and bundle no C runtime.

| Component | Used for | Builds | License |
| --- | --- | --- | --- |
| [Zig](https://ziglang.org/) standard library and compiler runtime | Runtime support compiled into every binary | All | MIT |
| [Ghostty](https://github.com/ghostty-org/ghostty) | Terminal emulation; `src/input` adapts its key and mouse encoders | All | MIT |
| [uucode](https://github.com/jacobsandlund/uucode) | Unicode properties | All | MIT, with Unicode data under the Unicode License v3 |
| [simdutf](https://github.com/simdutf/simdutf) | Fast UTF-8 and base64 decoding | All | MIT (dual-licensed with Apache-2.0), with code derived from PyTorch under BSD-3-Clause |
| [Highway](https://github.com/google/highway) | SIMD dispatch | All | BSD-3-Clause (dual-licensed with Apache-2.0) |
| [Wuffs](https://github.com/google/wuffs) | Decompressing and converting kitty graphics images | All | MIT (dual-licensed with Apache-2.0) |
| [GNU Unifont](https://unifoundry.com/unifont/) 18.0.01 | Text in PNG snapshots | All | OFL-1.1 (dual-licensed with GPL-2.0-or-later with the GNU Font Embedding Exception) |
| [Noto Color Emoji](https://github.com/googlefonts/noto-emoji) 2.057 | Color emoji in PNG snapshots, as a prerendered atlas | All | OFL-1.1 |
| [FreeType](https://freetype.org/) 2.13.2 | Reading TrueType, OpenType, and bitmap fonts for PNG snapshots | Medium, full | FTL, with the BDF and PCF drivers under X11-style licenses |
| [zlib](https://zlib.net/) 1.3.1 | Decompression inside FreeType | Medium, full | Zlib |
| [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) 2.304 | Text in PNG snapshots | Medium, full | OFL-1.1 |
| [JuliaMono](https://github.com/cormullion/juliamono) 0.63.2 | Math symbols, arrows, and other text in PNG snapshots | Full | OFL-1.1 |
| [Symbols Nerd Font Mono](https://github.com/ryanoasis/nerd-fonts) 3.5.1 | Icons in PNG snapshots | Full | MIT, with icon sets under MIT, CC BY 4.0, Apache-2.0, and OFL-1.1 |
| [Noto Sans Mono CJK SC](https://github.com/notofonts/noto-cjk) 2.004 | Chinese, Japanese, and Korean text in PNG snapshots | Full | OFL-1.1 |
| [musl libc](https://musl.libc.org/) | C library | Linux | MIT |
| [mingw-w64](https://www.mingw-w64.org/) runtime | C runtime | Windows | ZPL 2.1 |

`0.4.0-alpha.10` release, FreeType 2.13.2 and zlib 1.3.1 are the versions that revision pins.
